Product

Understanding, not throughput

EOM is a personal thinking tool. You write what is on your mind, pick an intent, and get a calm reply. No feeds, no notifications, no social features. Dark, single-mode Material 3. Title: EOM. Home is HomeScreen.

On device

Settings init and Hive History open in main() before runApp. Theme is EomTheme.dark only.

Your choice of guide

OpenAI, Anthropic Claude, Google Gemini, or LiteLLM (persisted id LOCAL). Fallback when nothing is saved: Gemini.

One seam: cloud API keys and the LiteLLM master key both go through keyFor / setKey.

Usable guide: hasUsableGuide is true only when the active provider has a non-empty key. A key on another provider does not count.

Code wins over README: keys are on-device preference storage. They are not in git, and they are not loaded from .env.

Request path

Screens call an interface, not a vendor

lib/services/llm_provider.dart
abstract class LlmProvider {
  Future<String> generate(
    String systemPrompt,
    String userMessage, {
    List<ChatMessage> history = const [],
  });
}
extension LlmProviderKindFactory on LlmProviderKind {
  LlmProvider createProvider() {
    switch (this) {
      case LlmProviderKind.openai:
        return OpenAiProvider();
      case LlmProviderKind.anthropic:
        return AnthropicProvider();
      case LlmProviderKind.local:
        return LocalProvider();
      case LlmProviderKind.gemini:
        return GeminiProvider();
    }
  }
}

Factory lives in services: lib/models/ stays free of HTTP clients.

Tests: AiService({LlmProvider? provider}) injects a fake. Production reads SettingsService.activeProvider.createProvider().

Shared POST: OpenAI and Local share _postChatCompletion. Gemini uses x-goog-api-key, not a query string.

Request path

LOCAL means the LiteLLM gateway

ADR 0001: the Local slot is exclusively the LiteLLM gateway. Master key required. Model aliases. Gateway origin without /v1. Direct OpenAI / Anthropic / Gemini stay beside it so traffic is not forced through one box.

Identity

Persisted id LOCAL. Settings label LiteLLM. Legacy OLLAMA maps to Local in LlmProviderKind.fromString.

Origin rules

normalizeGatewayOrigin strips trailing slashes and optional /v1, requires http(s) + host, rejects userinfo. Empty origin falls back to the built-in default.

Cited: docs/adr/0001-local-means-litellm-gateway.md, lib/models/llm_provider_kind.dart, lib/services/settings_service.dart.

Deep dive · 2 of 3

The map under the surface

Every session can refine a personal knowledge graph that never leaves the device.

Epistemic graph

Six types, five origin categories

lib/models/epistemic_node.dart
enum EpistemicNodeType {
  belief,
  knowledge,
  hypothesis,
  intuition,
  question,
  unknown,
}
enum EpistemicCategory { empirical, rational, intuitive, abductive, revelatory }

Type is what the node is. Category is how the mind produced it. They are orthogonal. Confidence is a separate [0, 1] field.

Edges: entails, contradicts, refines, supports, undermines, isExampleOf (LLM kebab-case accepted).

Provenance: experience, reasoning, testimony, intuition.

Epistemic graph

Derived reads live on the abstract store

lib/services/sqlite_epistemic_graph_store.dart
abstract class EpistemicGraphStore {
  Future<EpistemicNode> create(EpistemicNode node);
  Future<EpistemicNode> upsert(EpistemicNode node);
  Future<EpistemicNode?> get(String id);
  Future<List<EpistemicNode>> all();
  Future<List<EpistemicNode>> byType(EpistemicNodeType type);
  Future<EpistemicRelationship> addRelationship(
    EpistemicRelationship relationship,
  );
  Future<List<EpistemicRelationship>> getRelationshipsForNode(String nodeId);

Primitives are abstract. Drift, maturity, and BFS traverse are concrete defaults on the class, so SQLite and in-memory fakes share semantics.

Search: FTS5 in production. sanitizeFtsQuery quotes tokens so user punctuation cannot inject MATCH operators.

Epistemic graph

Intents write the graph; gaps never do

lib/services/epistemic_intent_service.dart
/// Bridges intent responses to the epistemic graph (EOM-T7, EOM-T11).
///
/// Keeps [AiService] focused on LLM interaction and [SqliteEpistemicGraphStore]
/// focused on storage. Every thought session upserts the nodes derived

Clarify / Compress / Act persist a derived node, then keyword-overlap edges.

Map also carries a thought tree for the Home tree view.

Gaps (EOM-T14) are detected read-only. Detection never creates nodes.

Epistemic graph

Gaps, drift, and maturity are derived

Gaps

Explicit: question / unknown nodes. Inferred: session concepts with no covering node. FTS search, then substring coverage.

Drift

Confidence events, oldest first. Drift needs at least two values. Sorted by absolute movement. Not an observations table: that ADR is not in Dart yet.

Maturity

Per EpistemicCategory (null = uncategorised). High ≥ 0.7, uncertain < 0.4. Score is high / (high + uncertain), or null with no decided nodes.

lib/models/epistemic_maturity.dart
/// Confidence at or above which a node counts as *high-confidence*.

/// Confidence below which a node counts as *uncertain*.

Using the app

No key: a sheet, not a hard wall

    if (_controller.text.trim().isEmpty) {
      setState(() => _blankHint = 'Write a thought first.');
      _focusNode.requestFocus();
      return;
    }

    if (!SettingsService.hasUsableGuide) {
      final connected = await _openSoftGate();
      if (!connected || !mounted || !SettingsService.hasUsableGuide) {
        return;
      }
    }

Empty field: calm hint, never a silent no-op.

SoftGateSheet: provider pick + essential key only. Dismiss without Connect is cancel. Elevation 0. Motion through EomMotion.sheetStyleOf.

Settings: active-provider key first; LiteLLM origin and alias under collapsed Advanced.

Using the app

On-screen session is not the History library

Session
Home canvas: input, latest card, optional earlier turns, in-memory ChatMessage list sent to the model. ephemeral
History
Hive box conversations. Rows reopen on Home. Clear-all asks first. Presence pip uses hasConversations. on device
Errors
IntentError maps failures to calm copy. isError responses never enter History or the graph. Recoverable cases offer Open Settings.

New thought confirms, then clears the on-screen session. It does not delete History.

Working in this repo

Screens stop at services

lib/screens/

Home, History, Settings. Default to StatelessWidget. Stateful only for ephemeral UI (focus, expand, processing).

lib/services/

LLM, graph, settings, history, export, gaps. Abstract interfaces; tests fake the store, not sqflite.

lib/models/

Pure data. Relative imports inside lib/. No HTTP clients here.

Theming: never hardcode colors. Use EomColors. Zero elevation. Depth is a 0.5px surfaceBorder stroke. Ordinary radius 12px; leaf radius only at ceremonial empty / success card.
